# Image Switcher Alpha — selected visual concepts

These two AI-generated images were selected as **mockups**, not screenshots of the working editor:

- [Main editor concept](editor-main-concept.png): numbered photo rail, central image canvas, direct named adjustment sliders and a prominent Export action.
- [Export dialog concept](editor-export-concept.png): export settings appear in a focused modal only after Export is clicked.

The mockups are for layout/direction review before any UI rebuild. They contain illustrative imagery, placeholder numbers, and some AI-rendered text or controls that the alpha **does not implement** (for example clarity, denoise, whites/blacks, a reliable before/after comparison, and any suggestion that colliding files are silently skipped). The actual alpha refuses existing output names and cannot certify ownership or issue signed credentials. Do not treat these images as a list of shipped capabilities or an approved implementation specification.
