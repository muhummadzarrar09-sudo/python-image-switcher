# Image Switcher Alpha — selected visual concepts

These two AI-generated images were selected as **mockups**, not screenshots of the working editor:

- [Main editor concept](editor-main-concept.png): numbered photo rail, central image canvas, direct named adjustment sliders and a prominent Export action.
- [Export dialog concept](editor-export-concept.png): export settings appear in a focused modal only after Export is clicked.

The mockups guide the alpha.3 UI layout, but they are not screenshots of the implementation. They contain illustrative imagery, placeholder numbers and some AI-rendered text or controls that the alpha **does not implement** (for example Whites/Blacks, Clarity, Denoise, pixel-exact 100% RAW preview, and any suggestion that colliding files are silently skipped). The actual alpha includes a source/edited preview toggle; for NEF, source preview may use the embedded camera JPEG, not a pixel-exact comparison. Existing output names stop export without overwriting. The alpha cannot certify ownership or issue signed credentials; only the real editing controls should appear in the app.
